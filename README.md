# 🌟 Little Hero Chore Quest (ฮีโร่ตัวจิ๋วพิชิตงานบ้าน)
> เว็บแอปพลิเคชันสำหรับเด็กทำงานบ้าน มีเลือกงานบ้าน กำหนดเวลา เสียงเตือนอัตโนมัติ ถ่ายรูปประทับเวลาจริงบน Canvas และสะสมดาวแลกรางวัล

**Version:** 1.2.0  
**Revision:** rev-20261103-01  
**Framework:** React 19 + TypeScript + Vite + Tailwind CSS  
**Target:** รองรับทั้งคอมพิวเตอร์และโทรศัพท์ Android 100%

---

## 🚀 ฟีเจอร์เด่น
1. **ลายแทงแผนที่สมบัติ (Treasure Adventure Map):** หมุดวันที่ 1-30/31 ตามเดือนปัจจุบัน เด็กๆ ผจญภัยทีละก้าว ป้องกันการย้อนเวลา
2. **ระบบตั้งเวลาและเสียงเตือนภาษาไทย (Chore Alarm & Speech Synthesis):** ส่งเสียงพูดชื่อภารกิจ เช่น "น้องวิน ถึงเวลาล้างจานแล้วครับ" และดังซ้ำทุก 2 นาทีจนกว่าเด็กจะกดรับภารกิจ
3. **กล้องถ่ายรูปพร้อมประทับวันเวลาจริง (Canvas Auto-Watermark):** ประทับชื่อเด็ก วัน เดือน ปี เวลาจริงระดับวินาที พร้อมตราประทับความซื่อสัตย์ ป้องกันการใช้รูปเก่า
4. **สะสมดาว & ยศฮีโร่ 90 ดาวเต็มต่อเดือน:** แบ่งเป็น 6 ระดับ (เด็กขยัน 🌱, ผู้พิชิตภารกิจ ⚔️, พ่อบ้านจิ๋ว 1-3 🧹✨🛡️, แชมเปียนพ่อบ้านจิ๋ว 🏆)
5. **ลิงก์เฉพาะเด็ก (Player-Only Mode):** เข้าผ่าน `?mode=player` ล็อกสิทธิ์แอดมินและการลบงานบ้านด้วยรหัส PIN 4 หลัก (ค่าเริ่มต้น: 1234)
6. **ตรวจงาน & ส่ง LINE:** ส่งลิงก์ให้พ่อแม่ตรวจงาน ให้ดาวโบนัสพิเศษทาง LINE ได้ทันที

## 📦 วิธีติดตั้งและรันในเครื่อง (Local Development)
```bash
# ติดตั้ง dependencies
npm install

# รันโหมด Development (Port 3000)
npm run dev

# ทดสอบ Build ตรวจสอบข้อผิดพลาด
npm run build
```

## 🌐 วิธีนำขึ้น Vercel จากโทรศัพท์ Android (ฟรี 100%)
1. **เตรียมโค้ดบน GitHub:**
   - เข้าเว็บ [github.com](https://github.com) บนมือถือ แล้วล็อกอิน
   - กดปุ่ม **"+" ➔ "New repository"**
   - ตั้งชื่อ Repository เช่น `little-hero-chore-quest`
   - แตกไฟล์ ZIP ที่ดาวน์โหลดนี้ แล้วกด **"Uploading an existing file"** บน GitHub เลือกทุกไฟล์ขึ้นไป
2. **เชื่อมต่อและ Deploy บน Vercel:**
   - เข้าเว็บ [vercel.com](https://vercel.com) บนมือถือ แล้วล็อกอินด้วย GitHub
   - กดปุ่ม **"Add New..." ➔ "Project"**
   - เลือก Repository `little-hero-chore-quest` แล้วกด **"Import"**
   - Vercel จะตรวจพบ `vercel.json` และ Vite อัตโนมัติ ไม่ต้องตั้งค่าเพิ่มเติม
   - กดปุ่ม **"Deploy"** รอประมาณ 30 วินาที จะได้ลิงก์ `.vercel.app` ใช้งานได้ทันทีทั่วโลก!
